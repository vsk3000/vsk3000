# Редактор сайта для Windows

Запуск: `desktop-app/RouterSiteEditor.exe` или ярлык «Редактор сайта» на рабочем столе.

1. Выберите руководство и раздел слева.
2. Изменяйте заголовки и текст прямо на странице. Панель над текстом добавляет списки, ссылки, картинки и предупреждения. Нажмите на картинку для замены или удаления.
3. Кнопка «Предпросмотр» показывает черновик на компьютере и телефоне.
4. Черновики сохраняются автоматически. Для публикации один раз подключите свой GitHub, затем нажмите «Сохранить и опубликовать».
5. Дождитесь статуса «Опубликовано»: приложение проверяет, что новая версия доступна на GitHub Pages.

Кнопки ↑ и ↓ меняют порядок разделов. Вкладка «Отзывы и контакты» позволяет менять подписи и ссылки Авито. История сохранений восстанавливает черновик, не публикуя его автоматически.

Если сайт изменили с другого компьютера, приложение остановит публикацию, чтобы не затереть изменения. «Загрузить с сайта» получит свежую версию и сохранит текущие черновики в истории. При отсутствии интернета можно редактировать локально и опубликовать позже.

## Хранение данных

- `.site-editor/` — приватные черновики, история и профиль окна приложения, исключены из Git.
- `site-content/` — опубликованные снимки страниц. Скрипты сборки используют их вместо старого экспорта документа, чтобы повторная сборка не уничтожила правки из конструктора.
- `assets/uploads/` — добавленные изображения, отправляются на GitHub вместе со страницами.
- GitHub: `vsk3000/vsk3000`, ветка `master`. Пароли в приложении не вводятся. Вход проходит через Git Credential Manager и GitHub в браузере; учётные данные хранит штатный менеджер Windows. Приложение держит токен только в памяти и не добавляет его в сайт.

Приложение работает в отдельном окне Microsoft Edge с локальным сервером на 127.0.0.1. Python устанавливать не нужно для готового EXE. Требуются Microsoft Edge и Git for Windows с Git Credential Manager (на этом компьютере уже установлены). Папку `desktop-app` следует держать внутри папки сайта; ярлык указывает на неё. При закрытии окна сервер завершится примерно через 2,5 минуты; кнопка «Закрыть приложение» завершает его сразу.

## Разработка

`python editor/app.py --root C:/Users/User/Documents/mysite`

Зависимости: `beautifulsoup4`. Проверки: `python -m unittest discover -s editor/tests -v`.

Сборка Windows EXE: `python -m PyInstaller --noconfirm --onefile --windowed --name RouterSiteEditor --paths .tools --add-data "ui:ui" --distpath desktop-app --workpath editor/build --specpath editor editor/app.py`.

Публикация создаёт коммит через GitHub API и обновляет master без принудительной перезаписи. При конфликте новая версия не заменяет чужие изменения. Локальные рабочие HTML-файлы обновляются; Git-индекс и локальные коммиты приложение не меняет.
