# Руководство пользователя роутера

Адаптивный статический сайт в оформлении «Светлый справочник». Материалы и 27 изображений перенесены из Google Документа пользователя. Раздел настройки прокси Telegram удалён по просьбе владельца. В конце размещены два профиля Авито.

## Просмотр

Откройте `index.html` или запустите `python -m http.server 8318 --bind 127.0.0.1` из этой папки.

## GitHub Pages

Репозиторий: https://github.com/vsk3000/vsk3000. Сайт: https://vsk3000.github.io/vsk3000/.

GitHub Pages публикует содержимое корня ветки `master`. Для дальнейших обновлений изменяйте `index.html` и файлы в папке `assets`, затем сохраняйте изменения в этой ветке.

Сайт не требует сборки, серверной части или внешних библиотек. Ссылки на ресурсы относительные, поэтому сайт работает и в корне домена, и в подпапке репозитория.

## Повторная генерация

Локальный скрипт `scripts/build_site.py` обрабатывает сохранённый экспорт `source-materials/google-document.html`. Требуется Beautiful Soup (`pip install --target .tools beautifulsoup4`). Скрипт проверяет полное совпадение текста без пробельных символов, количество изображений и внутренние ссылки. Экспорт и служебные файлы исключены из Git.

Контент Google Документа переносится снимком; последующие изменения документа не синхронизируются автоматически.

## Xiaomi AX3000T

Отдельная страница `ax3000t.html` описывает OpenWrt + Podkop и особенности авторской сборки, с ссылками на источники и официальную документацию. Основное руководство и страница AX3000T связаны ссылками в меню. Раздел прокси Telegram в обеих инструкциях отсутствует.

Текст редактируется в `scripts/ax3000t-content.html`. После обновления основной страницы запустите `python scripts/build_ax3000t.py`: общие разделы OpenWrt будут взяты из основной инструкции, иллюстрации будут загружены в `assets/ax3000t`, если их ещё нет. Для чтения метаданных иллюстраций требуется локальная копия источника `source-materials/perspektiva.html`. Текст и изображения на опубликованном сайте не требуют внешних библиотек.
